# Recursos visuales

## Recursos incluidos

| Recurso | Origen | Uso |
|---|---|---|
| Símbolo de TuEmpuje | Identidad del proyecto | Encabezado e identidad de la aplicación |
| Empu | Ilustración vectorial creada para el proyecto, escena editable en Rive | Encabezados, cuenta y estados vacíos |
| Iconos Material | Dependencia `material-icons-extended` del proyecto | Navegación, categorías y acciones |
| Tipografía sans serif | Fuente del sistema Android | Títulos, contenido y controles |

Los iconos Material se distribuyen bajo la [licencia Apache 2.0](https://github.com/google/material-design-icons/blob/master/LICENSE), el runtime de [Rive para Android](https://github.com/rive-app/rive-android/blob/master/LICENSE) usa la licencia MIT y el recurso exportado incluye la presentación del plan gratuito, la aplicación no incorpora fotografías ni ilustraciones descargadas de bancos externos

Se revisaron las condiciones generales de [unDraw](https://undraw.co/license), [Storyset](https://storyset.com/terms), [LottieFiles](https://lottiefiles.com/page/license), [Pexels](https://www.pexels.com/license/) y [Unsplash](https://unsplash.com/license/), antes de incorporar un recurso concreto deben comprobarse también sus condiciones particulares y la atribución aplicable
